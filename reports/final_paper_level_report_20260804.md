## 四、创新点

### 1. 多生成器多样性驱动 (贡献 52.5%+3%+3.6%+3.6% = 62.7%)
不同基座模型互补（14B×3 + 32B×1），同模型不同 LoRA 零互补。

### 2. 列接地 Column Grounding (贡献 6.2%)
与 value grounding 对称的新概念：修 SELECT 列选择。95% 失败是列选择错误。

### 3. 同池 Tournament Judge (贡献 17.0%)
GLM 同池候选 pairwise judge > 跨系统 judge。top-5 最优。

### 4. 深度重新生成 (贡献 6.9%)
完整 DB 上下文 → GLM-5.2 从零生成，对盲区题比候选重选更有效。

联合 oracle: 1286 → ~1288（72B Q4_K_M 贡献微弱）。距 90%（1381）仍差 93 题。

## 六、距 90% 分析

| 指标 | 值 |
|---|---|
| 当前最佳 | 1213 (79.07%) |
| 联合 oracle 上限 | 1286 (83.83%) |

**90% 不可达**：即使加 72B Q4_K_M，联合 oracle ~1288 < 1381。
需要：(1) 72B+ bf16 模型（需 >119GB GPU），或 (2) 专门微调到 EX>85% 的生成器。
