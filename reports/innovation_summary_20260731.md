## 三、创新点提炼

### 创新点 1：多生成器多样性驱动的候选池扩展
**做法**：不依赖单一生成器，而是合并多个 train 微调模型（4×14B）的 n8 温度采样候选，再逐步加入新生成器（Qwen3-sqlplus、OmniSQL-continue、Qwen2.5-Coder-32B），每加一个都带来新增 oracle 覆盖（15-16 题）。

**创新价值**：
- 生成器多样性比单个强生成器更重要（Qwen3-direct-r16 零新增覆盖，说明同模型不同 LoRA 不互补；不同基座模型/不同训练方式才互补）
- ORM 打分是必须步骤（未打分只有 +2，打分后 +10——正确候选排名提升后才进 tournament top-8）

### 创新点 2：按需探查的 Agent Harness（Active-Probe Agent）
**做法**：不是一次性把所有信息塞进 prompt，而是让 agent 主动探查 DB 获取正确信息：
- **值探查（E3v）**：WHERE literal → DB cell 模糊匹配
- **列接地（E3c）**：SELECT 列 → 语义匹配 + 列样本对比 ★ **核心创新**
- **JOIN 修复（E2）**：FK 图最短路径诊断 + 执行去噪
- **深度重新生成（Deep Regen）**：完整 DB 上下文 → GLM-5.2 从零生成

**创新价值**：
- **列接地（Column Grounding）**：与 value grounding 对称的新概念——value grounding 修 WHERE 的值，column grounding 修 SELECT 的列。此前所有 NL2SQL 工具都忽略 SELECT 列选择，而这恰是 95% 失败的根因。
- **按需探查 vs 静态塞入**：不盲目全塞 cell 值/schema，而是草图驱动——先 draft，标记不确定性，针对性探查。
- **深度重新生成**：对盲区题，fresh generation（完整上下文）比 candidate reselection 更有效（+21）。

### 创新点 3：同池候选 Tournament 重选（Route A）
**做法**：ORM top-5 knockout tournament——GLM 同池候选 pairwise judge（执行结果，无 gold），选优。

**创新价值**：
- **同池 judge 比跨系统 judge 可靠得多**（跨系统 rescue=61 damage=105，同池 rescue=52 damage=0）
- **top-5 是最优配置**（top-3 +10, top-5 +27, top-8/12 饱和）
- **ORM 打分让正确候选进入 top-8** 是前提（未打分时正确候选排名太低）

### 创新点 4：层间隔离的可复现消融
**做法**：每个模块独立验证（rescue/damage/net），不依赖其他模块；每层都有完整消融。

**创新价值**：
- **确定性层（E3v/E4/E2/E5det）零损坏**（可选部署）
- **LLM 层（E3c/Deep Regen/Route A）有损坏但净正**（需消融控制）
- **全流程零损坏部署路径**：GLM base → detVG → merged4 ORM → E3v+E4+E2+E5det = 1106（可用 72.10%）
