## 二、关键发现：Agent Harness 的边际收益取决于基座质量

| 指标 | GLM-5.2 基座 | merged4 基座 |
|---|---:|---:|
| 基座 EX | 908 | 1068 |
| E3v 值错误题数 | 167 | 106 |
| E3v 增量 | **+53** | **+3** |
| E4 增量 | +6 | +2 |
| **agent 总增量** | **+59** | **+5** |

**核心结论**：
1. **生成器基座越强，agent harness 的边际收益越小**（GLM 上 +59 vs merged4 上 +5）。
2. **merged4 是更强的生成器**（1068 vs 908，+160），但 agent 层在它上面几乎饱和（+5）。
3. **最佳组合是"强生成器 + 轻量 agent"**：merged4(1068) + E3v+E4 = 1073。
4. 这说明 merged4 模型的失败主要是**真正的能力盲区**（结构复杂、多表关系、罕见模式），而非"缺正确信息"——agent 工具探查补不了。

- **90% 不可达的根本原因**：生成器 oracle 上限（1223）< 90%（1381）。需要更强的生成器基座（如 70B+ 或专门微调到 EX>75%）。
