## 四、创新点：列接地（Column Grounding）

**与 value grounding 的对称关系**：

| | Value Grounding (E3v) | Column Grounding (E3c) |
|---|---|---|
| 修什么 | WHERE 子句的**值** | SELECT 子句的**列** |
| 探查什么 | DB cell 实际值 | DB 列名 + 列样本 |
| 匹配方式 | case-insensitive + fuzzy | 语义匹配 + 列样本对比 |
| 增量 | +53 (GLM基座) / +3 (merged4) | **+19 (merged4)** |

**创新价值**：此前所有 NL2SQL agent/工具都聚焦 WHERE 值和 JOIN 路径，**忽略 SELECT 列选择**——而这恰是 95% 失败的根因（深度拆解发现 434/457 题是列选择错误）。E3c 填补了这个盲区。
